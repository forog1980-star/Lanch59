# LAUNCHER 59

لانچر دایره‌ای شناور، مینیمال و شیشه‌ای برای دسکتاپ ویندوز ۱۰ و ۱۱ (Windows 11 Glassmorphism / Acrylic).

- **نسخه فعلی:** `2.0.2`
- **موتور دسکتاپ:** Electron `45.3.4` (Windows x64)
- **صفحه آخرین انتشار:** [GitHub Releases (Latest)](https://github.com/forog1980-star/Lanch59/releases/latest)

---

## دانلود نسخه ویندوز (v2.0.2)

- **نسخه نصبی (Setup):** [Launcher59-Setup-2.0.2-x64.exe](https://github.com/forog1980-star/Lanch59/releases/download/v2.0.2/Launcher59-Setup-2.0.2-x64.exe)
- **نسخه قابل‌حمل (Portable):** [Launcher59-Portable-2.0.2-x64.exe](https://github.com/forog1980-star/Lanch59/releases/download/v2.0.2/Launcher59-Portable-2.0.2-x64.exe)
- **فایل بررسی اصالت (SHA256):** [SHA256SUMS.txt](https://github.com/forog1980-star/Lanch59/releases/download/v2.0.2/SHA256SUMS.txt)

### تفاوت نسخه Setup و Portable
- **Setup (`Launcher59-Setup-2.0.2-x64.exe`):** برنامه را در مسیر کاربری ویندوز (`%LOCALAPPDATA%\Programs\LAUNCHER 59`) بدون نیاز به دسترسی Administrator نصب می‌کند، میانبر منوی Start و دسکتاپ می‌سازد و در بخش حذف برنامه‌های ویندوز (Uninstall) ثبت می‌شود.
- **Portable (`Launcher59-Portable-2.0.2-x64.exe`):** بدون نصب، مستقیماً اجرا می‌شود و برای آزمایش سریع یا اجرا از فلش و پوشه دلخواه مناسب است.

## قابلیت‌های اصلی نسخه 2.0.2

- **گوی مرکزی شیشه‌ای ۵۹ + حلقه شعاعی برنامه‌ها:** طراحی مینیمال دایره‌ای با هاله نوری آبی ویندوز ۱۱، پیمایش صفحه‌ای حلقه و اجرای مستقیم فایل‌های `.exe`، پروتکل‌های سیستمی و وب‌سایت‌ها.
- **موقعیت‌یابی پویا ۹گانه و پایداری چندمانیتوره:** قرارگیری سریع در مرکز، لبه‌ها یا ۴ گوشه صفحه + جابه‌جایی آزاد با Drag و تطبیق خودکار هنگام تغییر مانیتور یا رزولوشن.
- **بازشدن تطبیقی حلقه (Adaptive Radial Menu):** در لبه‌ها و گوشه‌ها حلقه به‌صورت موقت به سمت فضای آزاد داخل نمایشگر باز می‌شود تا تمام آیکون‌ها و برچسب‌ها کاملاً دیده شوند و پس از بسته‌شدن به جای قبلی بازگردد.
- **کاهش شفافیت خودکار در بیکاری (Smart Idle Auto-Fade):** تنظیم میزان شفافیت و زمان انتظار در تنظیمات با بیدارشدن فوری هنگام اشاره ماوس.
- **ذخیره‌سازی کاملاً محلی و آفلاین:** تمام تنظیمات و میانبرها در `%APPDATA%\launcher-59\` ذخیره می‌شوند و هیچ وابستگی ابری ندارد.
- **کنترل از System Tray:** دسترسی سریع به باز/بستن حلقه، تنظیمات، حالت Always on Top و خروج کامل.

## نیازمندی‌های نصب و نکته امنیتی

- **سیستم‌عامل:** Windows 10 یا Windows 11 (معماری 64 بیتی `x64`)
- **فضای دیسک موردنیاز:** حدود ۴۰۰ مگابایت برای نصب کامل
- **نکته امضای دیجیتال (Unsigned Build):** فایل‌های اجرایی این انتشار فاقد گواهی امضای دیجیتال تجاری (Code Signing) هستند. در صورت نمایش هشدار Windows SmartScreen، از مسیر **More info → Run anyway** اقدام کرده و پیش از اجرا، مقدار SHA256 فایل دانلودشده را با `SHA256SUMS.txt` مقایسه کنید.
